TOKEN LAUNCH RADAR

Every protocol that still records no token, ranked by what its token would be worth.

How the value is built

implied value = TVL × category multiple × growth × maturity × breadth. The category multiple is the median market-cap / TVL of the protocols in the same category that already have a token, read from this snapshot — never a name on a list. Growth is the 7-day TVL change, maturity is how long the protocol has run, breadth is how many chains it runs on. Token-bearing protocols never enter the board; they only calibrate the multiples. Wrapped, staked and bridged products, exchanges and versioned copies are not launch candidates — the snapshot's own watchlist rule leaves them out, and so does this board; the count left out is shown in the snapshot line below. A protocol is shown as recording no token, never as having none — the snapshot is the record, not proof.
